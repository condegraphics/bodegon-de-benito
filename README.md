# Bodegón de Benito

One-page estática para El Bodegón de Benito, desarrollada con HTML5 semántico y CSS3 puro.

## Contenido

- `index.html`: estructura, SEO on-page, datos estructurados y enlaces oficiales.
- `style.css`: sistema visual responsive, accesible y sin frameworks.

## Vista pública

La versión publicada está disponible mediante GitHub Pages en:

https://condegraphics.github.io/bodegon-de-benito/

## Fuente de activos

Las imágenes, el logo y los enlaces de carta utilizados provienen de la web pública oficial:

https://elbodegondebenito.com/

Los horarios no se incorporan hasta contar con confirmación oficial.
